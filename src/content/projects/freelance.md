Since mid-2025 I've worked as an independent backend/full-stack engineer, splitting time between client delivery and a personal engineering project used to stay sharp on production-grade Python and cloud practices.

For client work — a healthcare provider and a community organisation (both confidential) — I built and deployed their websites, wired up GitHub Actions pipelines for automated deployment to Vercel, and containerised supporting services with Docker so client review and handover stayed low-friction. One engagement also involved integrating multi-provider LLM infrastructure (Gemini, Claude) with cost-aware routing, and shipping AI-driven features such as structured data extraction and intelligent matching.

In parallel, I designed and built a FastAPI + PostgreSQL backend for a personal CRM-style job-search tracker: a modular monolith with a strict layered architecture (routes → services → repositories → domain), Alembic migrations, Cognito-based JWT auth, and a pytest suite enforced in CI. The project is a deliberate way to keep AWS deployment and applied AI/LLM integration skills sharp between client engagements.
