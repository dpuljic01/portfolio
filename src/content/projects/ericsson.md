During an internship at Ericsson, I built a protocol-mapping tool for network engineers who needed to translate data between different vendor XML schemas — a process that was previously manual and error-prone.

The backend handled XML parsing and schema transformation logic in Python, with MongoDB storing the mapping rules and transformation history. A Node.js API layer exposed the transformation endpoints, and I built a React frontend that let engineers define and test mapping rules without writing code.

This project gave me early exposure to the full stack — backend logic, API design, data storage, and a usable UI — and introduced me to the complexity of working within large enterprise engineering organisations.
